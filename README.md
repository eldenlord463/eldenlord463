## 🚀 Featured Project

### ⚡ End-to-End Distributed Data Engineering Pipeline

A large-scale data engineering pipeline designed to process a **5.6 GB Kaggle dataset containing 43M+ records** using a distributed architecture.

**Pipeline:**

```text
Raw CSV
   ↓
HDFS Storage
   ↓
PySpark Processing
   ↓
Spark SQL
   ↓
Spark MLlib
   ↓
Matplotlib Analytics
   ↓
Interactive Dashboard
   ↓
Apache Airflow
```

### 📊 Pipeline Highlights

- **43M+ records** processed
- **5.6 GB** raw dataset
- Distributed storage using **Hadoop HDFS**
- Large-scale processing with **Apache Spark / PySpark**
- Analytical processing using **Spark SQL**
- Machine learning using **Spark MLlib**
- Automated orchestration using **Apache Airflow**
- Data visualization with **Matplotlib**
- Schema validation and data quality checks
- Fault-tolerant workflow design
- Parquet + Snappy compression
- Automated retries and SLA monitoring

### ⚙️ Engineering Optimizations

**Broadcast Joins & Partition Pruning**

Reduced expensive network shuffles by broadcasting lookup tables and applying partition pruning, achieving a reported **3.8× execution speed improvement**.

**Data Quality & Idempotency**

Implemented schema validation, quarantine paths for invalid records, and partition-level atomic overwrites to prevent duplicate data during pipeline reruns.

**Columnar Storage**

Converted raw CSV data into **Parquet with Snappy compression**, reducing storage from **5.6 GB to 1.8 GB**.

**Automated Orchestration**

Designed Airflow DAGs with retries, dependency handling, SLA monitoring, and automated alerts.
